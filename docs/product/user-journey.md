# InvestGuide User Journey

The ideal InvestGuide journey moves a user from curiosity to confident long-term financial understanding. AI supports every stage as an interpreter, tutor, and research companion, not as a financial advisor.

## 1. Landing Page

User goal: understand what InvestGuide is and whether it is trustworthy.

AI role: explain the platform promise in plain language, surface examples, and reinforce the educational-not-advisory boundary.

Key product outcome: user understands InvestGuide helps financial decisions through intelligence, education, and context.

## 2. Signup

User goal: create an identity so the platform can remember their profile and progress.

AI role: none required during signup except future copy assistance and trust messaging.

Key product outcome: authenticated user exists.

## 3. Onboarding

User goal: tell InvestGuide their experience, goals, risk appetite, horizon, and preferred assets.

AI role: explain why each question matters and later summarize the profile.

Key product outcome: investor profile exists and personalizes the product.

## 4. Dashboard

User goal: see the most relevant market, education, and planning information.

AI role: explain market context, summarize changes, and suggest research or learning next steps.

Key product outcome: user knows what matters today and why.

## 5. Education

User goal: learn concepts needed for better decisions.

AI role: tutor concepts, adapt language, create examples, and answer questions.

Key product outcome: user increases financial literacy and confidence.

## 6. Investment Research

User goal: investigate assets, REITs, sectors, news, and macro effects.

AI role: summarize asset intelligence, explain metrics, compare alternatives, and surface risks.

Key product outcome: user can compare options with clearer tradeoffs.

## 7. Portfolio

User goal: monitor holdings, diversification, income, and goal alignment.

AI role: explain portfolio exposure, concentration, risk, and changes over time.

Key product outcome: user understands their financial position better.

## 8. Roadmap

User goal: know what to do or learn next over weeks, months, and years.

AI role: generate educational and planning roadmaps based on profile and progress.

Key product outcome: user has a long-term path rather than isolated actions.

## 9. Long-Term Engagement

User goal: keep learning, revisiting goals, adapting to market changes, and tracking progress.

AI role: remember profile context, explain changes, recommend learning, and prompt periodic reflection.

Key product outcome: InvestGuide becomes a trusted financial intelligence companion.

## Journey Safety

At every stage, InvestGuide must:

* remain educational
* cite sources where factual claims are made
* avoid guarantees or trade instructions
* explain uncertainty
* preserve user agency
* adapt without manipulation
